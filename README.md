# Punch Runner

> A game about running and punching.

A game made for **Hack Club Jumpstart Haven** using **Godot**.

## Play the Game

**Itch.io:** https://samerthansam.itch.io/punch-runner

## About

Some shirtless dude in grey pants fights some other shirtless dudes with red pants while running in the desert because ganging up on a street fighter is probably a bad idea.

## Features

* Moving
* Punching
* Jumping
* Punching while Jumping

## Controls

* **Right Arrow** and **Left Arrow** for moving right and left respectively
* **Space** - Jump
* **Z** - Punch

## Built With

* **Engine:** Godot 4.7.2
* **Language:** GDScript
* **Assets:** OpenGameArt
